# 💰 Tip Calculator – Python Project

## 🧠 Objective
This program helps users quickly calculate how much each person should pay after adding a tip to the total bill.

---

## 🧩 How It Works
1. The user enters:
   - The total bill amount.
   - The tip percentage (e.g., 10%, 12%, or 15%).
   - The number of people to split the bill.
2. The program calculates the total amount including the tip.
3. It divides the total equally among all people.
4. Finally, it prints how much each person should pay.
