# 🏝️ Treasure Island Adventure Game (Python)

Welcome to **Treasure Island** — your mission is simple: **find the hidden treasure!**  
But beware… one wrong decision, and it’s *Game Over!* ⚔️

---

## 🎮 **How to Play**
1. Run the program.
2. Follow the on-screen story and type your choices:
   - Choose **left** or **right**
   - Then **wait** or **swim**
   - Finally pick a door: **red**, **yellow**, or **blue**
3. Each choice leads to a new outcome — can you survive and find the treasure? 🪙

---

## 🧠 **Concepts Used**
- Conditional statements (`if`, `elif`, `else`)
- String handling (`.lower()`, `.strip()`)
- User input (`input()` function)
- Nested logic and flow control
