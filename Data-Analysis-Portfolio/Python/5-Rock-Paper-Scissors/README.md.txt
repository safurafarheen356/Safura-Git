# ✊✋✌️ Rock Paper Scissors Game (Python)

A fun and simple **Rock–Paper–Scissors** game built in Python where you play against the computer.  
Can you beat the machine? 😎  

---

## 🎮 **How to Play**
1️⃣ Run the program.  
2️⃣ Choose your move:  
   - Type **rock**, **paper**, or **scissors**.  
3️⃣ The computer will also make its choice.  
4️⃣ The result — **You Win**, **You Lose**, or **Tie** — will be displayed on screen.
