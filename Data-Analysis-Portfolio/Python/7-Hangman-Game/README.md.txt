# Hangman Game (Python)

## Description
A command-line Hangman game built using Python.
The player guesses letters to reveal a hidden word before running out of lives.

## Concepts Used
- Python loops
- Lists
- Conditionals
- Random module
- Modular files (importing word list & art)

## Files
- hangman.py — main game logic
- hangman_words.py — word list
- hangman_art.py — stages & logo

## How to Run
```bash
python hangman.py
