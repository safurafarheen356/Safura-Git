# Caesar Cipher (Python)

## Description
A Python program to encrypt and decrypt messages using the Caesar Cipher technique.
Supports restarting the program and handles numbers, symbols, and spaces.

## Concepts Used
- Functions
- Loops
- Conditionals
- Modulus operator
- Importing modules

## Files
- caesar_cipher.py — main logic
- art.py — ASCII logo

## How to Run
```bash
python caesar_cipher.py
