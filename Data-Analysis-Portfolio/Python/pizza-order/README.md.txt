# 🍕 Python Pizza Order Program

## Project Description
This is a simple Python project that calculates the total bill for a pizza order based on user inputs.  
The user can choose pizza size, add pepperoni, and add extra cheese.

## Features
- Asks user for pizza size (S, M, L)
- Option to add pepperoni
- Option to add extra cheese
- Calculates and displays the final bill
